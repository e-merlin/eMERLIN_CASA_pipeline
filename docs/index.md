The e-MERLIN CASA Pipeline (eMCP) is a Python pipeline working on top of CASA to process and calibrate interferometric data from the e-MERLIN array. It provides:

- Automated data processing workflow for e-MERLIN observations
- Real-time weblog with data assessment plots and statistics
- Calibrated data output and preliminary images of relevant fields
- Support for mixed-mode data including narrow-band spectral windows
- Special observing modes like pseudo-wideband observations
